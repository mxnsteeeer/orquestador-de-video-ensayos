# Video-Ensayo Orchestrator

Orquestador de agentes especializados en video-ensayos serios para opencode.

Intención: conciencia vestida de lúgubre. Semilla pequeña, nunca sermón, nunca deprimir. Estructura similar, texto siempre nuevo, sin jerga en narración.

## Instalación

Copia `.opencode/` a tu proyecto, reinicia opencode.

```
cp -r video-ensayo-orchestrator/.opencode tu-proyecto/
```

## Uso

```
/video-ensayo ideas
/video-ensayo A dónde se fue el poder de las antiguas civilizaciones
```

Flujo: packaging serio → guion 10-12 min con 3 bloques que abren y cierran → narras 1 toma → edición lenta → SEO existencial.

## Agentes

- `escritor` — guion serio, 3 círculos completos, semilla sin nombrar
- `cinematografo` — edición lenta 6-10s, desaturado, drone
- `empaquetador` — títulos y miniaturas serias, sin clickbait agresivo
- `estratega-seo` — tags existenciales
- `ideador` — vestido / semilla scoring
- `critico` — anti-sermón, anti-calco, anti-depresión
- `productor` — checklist tú-solo-narras

## Estructura formato

1. HOOK 2 frases + 15s silencio
2. Pregunta marco
3. 3 bloques: abre → contexto → cierra
4. Espejo (barrio, familia, tú)
5. Semilla (3-4 frases rendija)
6. Gracias por ver.

Ver `examples/` y `templates/`.
